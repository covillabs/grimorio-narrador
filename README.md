# Grimório Narrador

Sistema de gerenciamento para Mestres de Vampiro: A Máscara (V5).

## Funcionalidades
- Fichas de Personagem (Vampiro, SPC)
- Gerenciamento de Coterie
- Controle de Domínio
- Automação de mecânicas V5 (Fome, Críticos, etc.)

## Tecnologias
- React + Vite
- TypeScript
- Shadcn UI
- Python (MCP Server)

## Instalação
1. Clone o repositório
2. Crie o ambiente virtual: `uv venv`
3. Instale as dependências frontend: `npm install`
